# iTP CyberSec Team Portal

A simple internal web portal built for the **iTP CyberSec Team** to support challenge-based learning and friendly competition.

## Purpose

This website is designed as a **flag submission system** for cybersecurity challenges created by Team Leaders.  
Members solve challenges, submit flags, earn points, and track their progress over time.

The goal is to encourage:
- Hands-on learning
- Consistent participation
- Friendly competition within the team

## Features

### 🏁 Submit a Flag
Team members can submit flags for challenges released by Team Leaders.  
Each correct submission contributes to the user’s score.

### 🏆 Rankings
A leaderboard that ranks team members based on their total score.  
This promotes healthy competition and motivates continuous improvement.

### 🎖 Achievements
Achievements reward milestones such as:
- First correct flag
- Multiple successful submissions
- High rankings

Achievements are meant to recognize effort, not just score.

## Design Goals

- Clean and minimal UI
- Focus on usability over visual noise
- Responsive and modern layout

## Intended Users

- **Team Leaders**: create challenges and manage scoring
- **Team Members**: solve challenges, submit flags, and track progress

## Status

This project is currently under active development.  
Future improvements may include authentication, challenge listings, and enhanced user profiles.
